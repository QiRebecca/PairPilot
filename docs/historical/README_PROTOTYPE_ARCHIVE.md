# Historical README snapshot

This file preserves the context that was removed when the repository README
was rewritten for the final PairPilot V1 submission on 2026-09-01. It is a
historical index, not a description of the submitted product and not evidence
that the final product was tested by the earlier reports.

- a shared, named Qi/Alice/Maya/Lena synthetic walkthrough;
- an intent-layer candidate deployed at zero traffic;
- a public-beta candidate that still had launch gates;
- one-sided or single-scenario approval demonstrations;
- a relationship-graph-led interface rather than the final authenticated app.

in the date-stamped evidence reports below. Their wording and metrics have not
